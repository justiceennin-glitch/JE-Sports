JE SPORTS — LIVE FOOTBALL STARTER

Included:
- Mobile-friendly live scores interface
- Fixtures and results
- League/table section
- Search
- Refresh button
- Easy structure for adding a real football-data API

IMPORTANT:
The included match information is DEMO data. It is not real-time.
For real live scores, connect a licensed football-data provider/API.
This package intentionally does not include betting, bookmaker integration,
SportyBet booking codes, or gambling functionality.

HOW TO USE:
1. Extract the ZIP.
2. Open index.html in a browser.
3. To publish it, upload the extracted files to a static web host.
